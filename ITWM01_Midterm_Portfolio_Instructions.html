Build your own personal portfolio.

Create a simple, responsive portfolio website using React.js and Bootstrap 5. Introduce yourself, highlight your skills, and showcase your projects using reusable React components.

01 / Overview

Your task

You are a student learning modern web development. Your task is to build a personal portfolio website that presents your background, skills, and sample projects in a clear and professional way.

01

Introduce yourself

Create a welcoming hero section with your name, a short introduction, and a profile photo or avatar.

02

Show your strengths

Present your technical or professional skills and highlight at least two academic or personal projects.

03

Build with React

Organize your interface into components and use Bootstrap 5 to make your design responsive.

Remember: Your website must use React JSX and Bootstrap classes. A plain HTML page that only looks like a portfolio does not meet the React requirements.
02 / Website requirements

Sections you must include

Your portfolio should contain all seven sections below. You may customize the colors, typography, layout, and overall style as long as every required section is present.

A

Navigation Bar

Display your name or personal brand and links to the main sections of your portfolio.

HomeAboutSkillsProjectsContact
B

Hero Section

Include your full name, a short introduction or role, a profile photo/avatar, and a button linking to another section.

C

About Me

Write a short introduction about yourself. Include your course, year level, interests, or career goals.

D

Skills

Display at least four technical or professional skills. Use Bootstrap badges, cards, lists, or progress bars.

E

Projects

Show at least two academic or personal projects. Each needs a title, short description, and image or visual representation.

F

Contact

Display an email address and at least one other contact detail or social profile link. A sample email is acceptable.

G

Footer

Include your name or personal brand and a copyright notice.

R

Responsive layout

Use Bootstrap's grid system and responsive utilities so your website is readable on both small and large screens.

03 / React requirements

Show that you understand React

Your project will be evaluated not only on appearance but also on how you organize and reuse your code.

Required concepts

  • Use JSX to define the website interface.
  • Create functional React components.
  • Import and export components correctly.
  • Use at least one reusable component.
  • Pass data to a component using props.
  • Apply Bootstrap classes within JSX.

Example: a reusable component with props

For example, you can create one component for a skill and reuse it to display different skills.

function Skill({ name }) {
return <span className="badge text-bg-primary me-2">{name}</span>;
}

export default Skill;

This is an example to help you understand props. You are responsible for building and integrating your own components.

04 / Suggested workflow

How to complete the examination

1

Prepare your project

Open the provided React + Vite starter project and confirm that it runs.

2

Create your components

Build the navigation, hero, about, skills, projects, contact, and footer components.

3

Apply Bootstrap

Use Bootstrap's grid, spacing, buttons, cards, and responsive classes.

4

Use props

Pass information to at least one reusable component rather than repeating the same markup.

5

Test and submit

Check navigation links, layout, content, and responsiveness. Run the app before submitting.

Before you submit

  • All required sections are included.
  • Components are imported and rendered.
  • At least one component receives props.
  • Bootstrap styling is visible and consistent.
  • Links and buttons work as intended.
  • The layout works on mobile and desktop.
  • The project runs using npm run dev.
